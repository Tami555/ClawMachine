## 🎮 Как играть

**Скачать и запустить (без Unity):**
1. Скачай `.zip` из [Releases](../../releases/latest)
2. Распакуй архив в любую папку на компьютере.
3. Запусти `ClawMachine.exe`.
4. Играй!

> ⚠️ **Важно:** запускай `.exe` **из распакованной папки**, а не отдельно — игре нужны соседние файлы (`_Data`, `UnityPlayer.dll`).
>
> 💡 Если игра не запускается — установи [Microsoft Visual C++ 2015–2022 Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe).
